# braille-trainer
Портативный тренажёр рельефно-точечного шрифта Брайля на Arduino
Портативное автономное устройство для тренировки письма и чтения на рельефно-точечном шрифте Брайля. Себестоимость ~1800 руб.

Железо
Arduino Uno / Nano (ATmega328P)
DFPlayer Mini (HW-247A) + динамик 8 Ом
6 кнопок с фиксацией PB22E06 (точки 1–6)
4 тактовые кнопки (Проверка, Режим, Громкость ±)
Сборка
Соберите схему по schema_braille_trainer.png
Запишите файлы из SD_MP3/ на microSD в папку MP3/
Загрузите BrailleTrainer.ino в Arduino через Arduino IDE
Проверить кнопки можно через ButtonTest__2_.ino
